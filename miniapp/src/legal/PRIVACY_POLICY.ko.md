## 1. 개인정보 처리 목적

회사는 다음 목적으로만 개인정보를 처리합니다.

1. 토스 로그인으로 이용자를 식별하고 세션을 유지
2. 음성 분석 수행 및 결과 제공
3. 상세 리포트·정밀 진단 이용 권한 확인
4. 인앱결제 주문 검증, 구매 복구, 환불 시 권한 해제
5. 분석 기록 표시 및 정밀 진단과 원본 녹음의 연결
6. 이용자의 분석 삭제 요청 처리
7. 보안(비정상 요청 제한) 및 장애 대응

마케팅 광고 전송 목적으로 개인정보를 처리하지 않습니다.

## 2. 처리하는 개인정보 항목

항목을 출처별로 구분합니다.

### A. 토스로부터 제공받을 수 있는 정보

| 항목 | 실제 처리 |
| --- | --- |
| 이용자 식별값(`userKey`) | 계정·결제·기록의 기준. 저장함 |
| 이름 | 앱인토스 콘솔에서 이름 동의를 받는 경우 로그인 응답에 **포함될 수 있음**. 회사는 **읽거나 저장하지 않으며** 식별·결제에 사용하지 않음 |
| 이메일, 성별, 생년월일, 국적, 휴대전화, CI | 콘솔에서 사용 안 함. 수집하지 않음 |

인가 코드는 로그인 순간에만 서버로 전달되며 저장하지 않습니다. 토스 액세스·리프레시 토큰은 서버 메모리에서 로그인 조회에만 쓰이고 저장·재전달하지 않습니다.

### B. 이용자가 직접 제공하는 정보

- 녹음·업로드 음성 파일 및 파일명
- 정밀 진단 추가 녹음
- 고민 선택, 불편감 관련 예/아니오 응답(안전 확인)

### C. 서비스가 생성·추론하는 정보

- 분석 식별값, 처리 상태, 시각
- 발성 타입, 기능·음색 관련 분석 결과, 신뢰도·근거 구간
- 정밀 진단 세션, 원본 분석과의 연결값, 진단 리포트

### D. 결제 과정에서 회사가 생성하는 기록

- 토스 주문 식별값, 상품, 해당 분석 건, 결제·환불 상태, 이용 권한 상태  
- **카드번호·결제수단 원문은 저장하지 않습니다.**

### E. 서버 운영 정보

- 애플리케이션은 접속 IP·User-Agent를 **저장하지 않습니다.** IP는 로그인·결제 요청의 단기 횟수 제한에만 쓰일 수 있습니다.
- 처리되지 않은 오류는 요청 식별값, 경로, 오류 유형을 로그할 수 있습니다.
- 배포 환경의 리버스 프록시 접속 로그 여부는 **TODO_BEFORE_PRODUCTION**입니다.

기기 `sessionStorage` / `localStorage`에는 세션 토큰, 최근 파일명, 분석 기록 캐시 등이 남을 수 있습니다. 광고·분석 SDK는 사용하지 않습니다. 글꼴은 앱에 포함하지 않고 기기 기본 서체를 사용하며, 외부 글꼴 CDN으로 개인정보를 보내지 않습니다.

## 3. 개인정보 처리 및 보유기간

코드에 일수 단위 보관기간이 없는 항목은 숫자를 지어내지 않습니다.

| 구분 | 보유 |
| --- | --- |
| 로그인 세션 | 발급 후 12시간(토큰 만료). 토스 연결 해제 콜백이 오면 그 시점부터 해당 세션은 더 이상 유효하지 않음 |
| 음성·분석 파일 | 별도 만료 없음. 이용자가 해당 분석을 삭제하면 서버에서 삭제 |
| 정밀 진단 세션·과제 녹음 | 원본 분석에 명시적으로 연결된 경우, 그 분석 삭제 시 함께 삭제. 연결 없는 기록은 별도 유지 |

| 결제·이용 권한 기록 | 분석 삭제와 다른 주기. 환불 확인 시 권한은 해제되나 거래 기록은 남을 수 있음 |
| 기기 저장소 | 브라우저/앱 저장소 정책. 탭 종료 시 세션 토큰은 사라질 수 있음 |

## 7. 개인정보 파기

1. 이용자가 특정 분석을 삭제하면 해당 음성·분석 결과와, 그 분석에 명시적으로 연결된 정밀 진단 녹음·결과를 서버에서 삭제하고 분석 기록을 삭제 상태로 표시합니다.
2. 결제·주문·환불 확인 기록은 분석 삭제와 함께 지우지 않을 수 있습니다.
3. 토스 로그인 연결 해제는 세션을 무효화하며, 그 자체로 모든 분석 데이터를 삭제하는 기능이 아닙니다.
4. 회사는 토스 계정 회원탈퇴를 대신 수행하지 않습니다.
5. 파기 방법은 파일 삭제 및 데이터베이스 상태 갱신입니다. 백업 매체 파기 절차는 **TODO_BEFORE_PRODUCTION**입니다.

## 9. 개인정보의 안전성 확보조치

현재 구현된 조치만 적습니다.

- 결제·소유·분석 삭제는 서버가 검증한 토스 `userKey` 세션(HMAC)을 사용
- 토스 로그인·주문 조회는 mTLS
- 이용 권한은 이용자·상품·분석 건이 일치할 때만 부여
- 운영 환경에서 모의 결제 우회 차단
- 토스 토큰·인가 코드를 클라이언트에 반환하지 않음
- 토스 연결 해제 시 해당 이용자의 세션을 폐기

“완벽히 안전”하거나 “유출되지 않는다”고 단정하지 않습니다. 데이터베이스 접근 통제·암호화 세부(저장 암호화, 키 관리)는 배포 환경에 따르며 **TODO_BEFORE_PRODUCTION**입니다.
