# Vocal Function Boundary (v2)

## CAN (conditional)

- Estimate functional glottal-source *behavior* via multi-family audio proxies  
- Support lighter/firmer *contact-related* profiles  
- Support strain/effort-*like* patterns from multiple independent observations  
- Describe resonance/timbre strategy without skill good/bad  
- Coach with exercises and pre/post acoustic response  

## CANNOT

- Determine actual vocal-fold anatomy  
- Prove exact vocal-fold closure  
- Prove laryngeal muscle tension  
- Measure subglottal pressure / diaphragm / abdominal activation  
- Use one ideal target for all styles  

Internal name: **FUNCTIONAL_STATE_ESTIMATE** (never ANATOMY_ESTIMATE).
