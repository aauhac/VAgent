# Toss live/sandbox evidence receiver

Human fills the numbered folders after Apps in Toss sandbox verification.

Do **not** store:

- access token
- refresh token
- authorization code
- private key
- session secret
- client secret (or equivalent)

Checklist: `CHECKLIST.md` — every gate starts as **NOT_RUN**.
